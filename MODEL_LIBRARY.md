# Mental Model Library — Initial Taxonomy

Curated starting taxonomy, not a claim that every model is universally valid. Every model should be versioned and linked to source, context, limitations, and examples.

## A. Cognitive psychology
System 1 / System 2; anchoring; availability; representativeness/base-rate neglect; confirmation bias; motivated reasoning; overconfidence; planning fallacy; loss aversion; framing; hindsight; affect heuristic; cognitive dissonance; authority/in-group/halo/status quo bias; sunk cost; regression to mean.

## B. Munger / multidisciplinary models
Inversion; incentives; opportunity cost; circle of competence; margin of safety; second-order thinking; latticework; lollapalooza effect; comparative advantage; specialization; compounding.

## C. Scientific method / epistemology
Hypothesis-prediction-test-update; falsifiability; disconfirming evidence; Bayesian updating; base rates/reference classes; correlation vs causation; operational definitions; measurement validity; reproducibility; independent verification; Occam's razor (not proof); steelman; observation vs inference vs interpretation.

## D. Systems / cybernetics
System boundaries; stocks and flows; reinforcing/balancing feedback; delays; nonlinearities and thresholds; emergence; leverage points; Goodhart's law; Ashby's requisite variety; control loop; adaptation; robustness; resilience; local vs global optimization; stable states, oscillation, instability; black-box reasoning; observable vs controllable variables; feedback overcorrection.

## E. Risk / decision theory
Expected value and utility; distributions and confidence intervals; scenario/stress/sensitivity analysis; fat tails; ruin and survival; margin of safety; optionality/real options; reversibility; staged commitment; pre-mortem; redundancy/diversification; value of information; regret minimization; robust decisions under deep uncertainty; Kelly criterion as theory only.

## F. Economics / strategy / organizations
Marginal thinking; incentives; principal-agent; comparative advantage; transaction costs; network effects; switching costs/moats; game theory/repeated games; cooperation/trust; competition; scale economies; prisoner's dilemma; metric gaming.

## G. Cognitive trap checklist
Anchoring, availability, confirmation bias, base-rate neglect, survivorship and selection bias, outcome/hindsight bias, overconfidence, planning fallacy, sunk costs, loss aversion, framing, status quo, endowment, authority, social proof/herding, halo, false consensus, attribution errors, self-serving bias, Dunning–Kruger (use cautiously), regression-to-mean neglect, gambler's/hot-hand fallacies, narrative fallacy, illusion of control, present bias, zero-risk/action/omission bias, scope neglect, conjunction fallacy, ecological fallacy, correlation-causation confusion, false dichotomy, straw man, ad hominem, appeal to nature/authority, cherry-picking, moving goalposts, motte-and-bailey, Texas sharpshooter, no-true-Scotsman, overgeneralization, unsupported slippery slope, weak analogy, argument from ignorance, begging the question, availability cascade.

This is a working checklist, not a definitive canonical “52” list. Distinguish cognitive biases from formal logical fallacies and reconcile duplicates.

## Model record template
ID/name/aliases; category/tags; plain explanation; usefulness and limits; diagnostic questions; practical steps; original example; related/conflicting models; source/author/publication/URL/page; evidence status; source claim vs OS synthesis; version/date; feedback and linked decisions.
