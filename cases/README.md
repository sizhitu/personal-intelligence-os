# 历史市场压力测试案例库

> 状态：v0.1 初始基准集。案例为研究与系统验证材料，不构成投资建议。

## 范围与原则
- 时间范围：2023-11-09 至 2026-11-09（最近三年）。本批次纳入 12 个可追溯的美股/半导体显著下跌事件。
- 事件选择覆盖宏观衰退担忧、利率与杠杆、政策/出口管制、财报预期差、AI 技术叙事和资本开支周期。
- 同一轮连续下跌中高度相关的日期应合并或标注为同一事件链，避免重复计数。
- 每个案例包含持仓/当事人视角与潜在获益方视角。获益方不只指做空者，也包括现金买家、相对价值投资者、替代供应商。
- 权重为**基于公开信息的回顾性演示初值**，不是历史真实参与者的实际权重，也不是经过统计拟合的客观参数。正式前瞻测试必须冻结信息截面和权重。
- 案例的事实、触发因素、机制推断、分析建议分开记录；来源不足处标记待补证，不可编造。

## 双时间截面协议
1. `as_known_at_event`：只允许使用当时已公开的信息；分析者不得使用未来财报、政策结果或最终价格路径。
2. `hindsight_validation`：事后补充价格恢复/继续下跌、盈利变化、政策变化等，用于检验假设，不得回写当时决策。
3. 每个分析必须注明事实与推断；历史结果不证明当时选择正确（防止结果偏差）。

## 权重与评分协议
- 权重只对当前视角、当前问题有效；各视角普通可权衡因素合计 100%。硬约束（法律、安全、流动性/破产底线、用户明确底线）单独作为 gate/veto，不进入 100%。
- 因素权重、方案表现评分、证据可信度是三个独立维度，不得混为一个分数。
- 雷达图展示因素重要性；方案比较另用评分矩阵/条形图；证据可信度单独标注。
- 每个案例至少做 ±20% 相对权重扰动并重新归一化；若首选方案变化，标记 `weight_sensitive=true`。
- 对投资案例，至少包含：基本面/盈利、估值/预期差、流动性/杠杆、政策/宏观暴露、组合风险；根据事件动态增删。

## 双视角要求
- 当事人/持仓者：事件发生时已经暴露于风险的人，先处理生存、流动性、thesis 是否破坏，再考虑交易。
- 获益方：必须明确获益机制和可执行性（空头、现金买家、对冲者或替代供应商），计入融资成本、挤压风险、流动性与机会成本。
- 不把“股价下跌”本身当作获益；空头需计入借券成本、回补风险和路径风险。

## 数据结构
- `events.json`：事件事实、来源、双视角分析和演示权重。
- `CASE_TEMPLATE.md`：新增案例统一模板。
- `VALIDATION_PROTOCOL.md`：回测/评分/校准协议。
- 后续原始数据文件只存合法公开来源的 URL、引用摘录（短）、下载时间、哈希和元数据；不整篇复制付费新闻。
