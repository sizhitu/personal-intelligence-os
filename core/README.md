# Core

The shared intelligence engine operates across all domains. Planned modules:
- context: resolve relevant user and domain context
- alignment: compare options with user-authored principles
- reasoning: first-principles decomposition and mental-model selection
- evidence: provenance, freshness, and uncertainty
- decisions: options, trade-offs, and decision records
- feedback: outcome reviews and methodology proposals

Domain modules provide context and rules; they do not create competing intelligence engines.
